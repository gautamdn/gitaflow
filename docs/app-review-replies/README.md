## Conventions

- One file per reply, named `YYYY-MM-DD-build-X.Y.Z-short-summary.md`.
- Each file has a context section explaining why the reply was needed and a "Reply (paste into App Store Connect)" section containing the exact text.
- The actual sending happens in App Store Connect — these files are drafts and a paper trail.
- Do not commit secrets (test API keys). The test-credentials reply file uses `<YOUR_KEY_HERE>` as a placeholder.
